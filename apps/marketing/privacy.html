Privacy Policy

How this website handles information about visitors.

Last updated: 2026.

Scope

This privacy policy applies to the public marketing website at travelagencycrm.in. The software application customers sign in to at app.travelagencycrm.in is a separate service and is covered by the terms agreed with the organisation that subscribes to it.

Information this website collects

This website is a static marketing site. It does not require an account, does not host login forms, and does not process booking or payment data. In the course of normal operation, web servers may automatically record standard technical data such as IP addresses, browser type and requested pages in server logs.

How information is used

Any technical data recorded by the web server is used only for operational purposes such as security, troubleshooting and keeping the site available. We do not sell personal information.

Cookies

This website does not set advertising or analytics cookies. It loads its fonts from a third-party font provider, whose privacy practices are governed by that provider's own policy.

Links to the application

The "Go to App" buttons on this website link to the login page of the Travel CRM application at app.travelagencycrm.in/login. Once you leave this website, the application's own terms and privacy arrangements apply.

Contact

If you have questions about this policy, please contact the Travel CRM team through the application or the organisation that invited you to use it.

Changes to this policy

We may update this policy as the website evolves. The "last updated" date above reflects the most recent revision.
